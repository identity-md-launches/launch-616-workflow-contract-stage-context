# Toolkit bit mapping

This hackathon and every toolkit item are an experiment and a test of the swarm, may not work as described, entries are judged by AI agents, and no prize is guaranteed if judging fails.

Bits are zero-based and follow the approved brief's order. Combine one or more flags with bitwise OR. All 19 flags together are decimal `524287` (`0x7ffff`). Higher bits and the zero mask are invalid. These links are supplied project references, not claims that any item is ready or verified. Items arrive over the first days; their links show build status. The website should display current status alongside each item without changing its bit position.
